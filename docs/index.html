⚙️ Funcionalidades

💡 Ocorrências Urbanas

6 categorias: iluminação, trânsito, água, energia, pavimentação e resiliência. GPS + câmera + evidências com hash SHA-256.

🗺️ GIS Georreferenciado

10.997 segmentos viários mapeados. Localização automática de logradouro, bairro, zona e CEP.

🏆 Gamificação

Ranking de cidadania com pontuação por ocorrências registradas e avaliações.

📋 Ordens de Serviço

Despacho automático, timeline de progresso, evidências antes/depois, cálculo de rotas.

🔒 LGPD

Exportação e exclusão de dados pessoais. Consentimento explícito. Anonimização em relatórios.

📊 Inteligência Operacional

Dashboard com indicadores, relatórios CSV/XLSX/PDF, alertas automáticos e métricas de SLA.

🛠️ Stack Tecnológico

Node.js 24 NestJS 11 React 19 Next.js 15 Flutter 3.32 PostgreSQL + PostGIS Redis Kafka Keycloak OIDC Docker Kubernetes Mapbox GL Leaflet OpenStreetMap Firebase FCM ECharts
