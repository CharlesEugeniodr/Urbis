# Contribuição — URBIS

Projeto proprietário da Sigma SIHF Soluções Analíticas S/A. Contribuições exigem autorização do mantenedor.

- branches: `develop`, `staging`, `main`;
- commits: Conventional Commits;
- PR obrigatório para integração;
- não versionar chaves, CPF, tokens, service accounts ou dados pessoais reais;
- alterar schema somente por migration incremental;
- atualizar OpenAPI, rastreabilidade e testes junto com mudanças de contrato;
- nenhuma regra documental/administrativa deve ser inventada para fazer um teste passar.
